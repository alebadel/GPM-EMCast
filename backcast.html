V1 Core vs V2 Wide, replayed over past quarters on today's release pattern

For every past quarter T since 2012Q1, the data are cut back to the point each series has reached today relative to the quarter being nowcast — GDP through T−1 or T−2, each monthly indicator through the same month offset — and both versions are run exactly as a live run would be. Each Trim-25 headline is scored against GDP YoY as it stands in today's data.
How to read it. This is an approximation of real-time performance, not a record of it. It uses today's final-vintage data (revisions to GDP and indicators are ignored — material for India and Indonesia), seasonal factors estimated on the full sample, and today's release pattern projected backwards. Those shortcuts flatter both versions about equally, so the page is fair for V1 Core vs V2 Wide and not for absolute accuracy. None of these numbers enter the country pages' history charts or the out-of-sample scoreboard. V2 is replayed Haver-only and without its single-indicator pool, neither of which enters its Trim-25 headline.
